# SAC Socket Accumulated Calculator

Sistemes Actuals de Computació (SAC) first assignment: Socket Accumulated Calculator.

## Abstract

To quick start this assignment run `./start.sh` it will start a tmux session with the server, the benchmark an a netcat to also manually test the server.

The development has been done following KISS (Keep it Simple Supid) and UNIX philosophy (do one thing and do it well), it uses standard python (tested with python 3.13) without needing virtualenv nor containers.


## Assignment

Implement a socket-based service that offers the following mathematical operations: add, sub, div, mult, sqrt, mean, and std.

Each client will send requests to the server. The time between requests will follow an exponential distribution with a configurable rate. The program will also allow adjusting the number of clients and the duration of the experiment.

During execution, log at least the number of active connections, the requests served, the errors, the volume of data exchanged, and the response time.

Justify the design and implementation considerations made under the DS (Distributed Systems) paradigm.

## Setup

It is recomended to have python >= 3.6, tmux, watch and netcat (openbsd vesion).

This has been tested on Ubuntu 24.04 and python 3.13

No additional packages required, o docker, no uv. Just standard python and unix tools available in almost any system.

## Usage example

The recommeded way to execute it is using a tmux script that will split the terminal and suggest the appropiate commands.

Run with tmux:

    ./start.sh

It can also be executed manually:

    - `sac-server` starts the calulator server at port 1234
    - `sac-client` connects to the server a does a simple test
    - `sac-bench` benchmarks the server
    - `sac-stats` print current stats based on the written log

Once the server is started you can connect to it with netcat: `nc localhost 1234`

Run the server:

    ./sac-server

The server can also be stared with `--no-stats` to avoid registring stats.

Manually test the server:

    nc localhost 1234
    1
    2
    3
    add
    # Will respond 6
    sqrt
    # Will respond 2.4494...
    0
    div
    # Will Respond Error: float division by zero

Test the server with sac-client

    ./sac-client

Run the benchmark

    ./sac-bench -c 5 -r 10 -d 30

You can also watch the stats with

    ./sac-stats


## Architecture

Uses a threaded python.

## Server interface 

The server (`sac-server`) accepts a plain TCP connection on port 1234. The user send a number or operation per line.
Numbers accumulate into a queue until an operation is send. The operation is applied to the accumulated numbres, cleaning the queue and just leaving the result so it can be used as the first value of the following operation.

It has been implemented the `clear` statement to empty the queue.
